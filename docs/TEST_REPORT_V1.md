## 외부 접근과 진단

`curl -I --max-time 20`으로 확인:

- `https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@0.10.32/wasm/vision_wasm_internal.wasm`: HTTP 200.
- `https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task`: 프록시 CONNECT 403, curl exit 56.

실행 환경 상태는 running / connected, 네트워크 정책은 restricted / enforced입니다. Google Storage 도메인이 허용 목록에 없습니다. 도메인 추가 초안 저장은 플랫폼 `INVALID_ARGUMENT`으로 실패하여 저장을 확인하지 못했습니다. 환경 설정에서 `storage.googleapis.com` 허용 후 새 연결로 모델 다운로드를 재확인해야 합니다. TLS/체크섬 검증을 비활성화하거나 비공식 모델로 우회하지 않았습니다.

초기 npm 설치의 기본 캐시 디렉터리 생성 실패는 `--cache /workspace/.npm-cache`로 해결했습니다. 초기 lint의 ref 포함 객체 접근 문제는 hook 반환값 구조 분해로 수정 후 통과했습니다. jsdom Canvas 미지원 출력은 명시적 테스트 모의 객체로 해결했습니다. 통과 결과는 수정 후 재실행한 것입니다.

## 실제 카메라 수동 점검 절차 (미실행)

1. HTTPS/localhost의 지원 브라우저에서 모델·WASM 도메인 허용 상태를 확인합니다.
2. 권한 허용 후 영상·랜드마크의 위치와 좌우 반전 정합성을 확인합니다.
3. 약한 미소·짧은 미소에는 개봉되지 않고 양쪽 미소 700ms 유지 후 개봉되는지 확인합니다.
4. 미소를 계속 유지해도 반복 개봉되지 않고, 중립 표정을 350ms 유지한 뒤 재시도할 수 있는지 확인합니다.
5. 얼굴을 가리거나 프레임 밖으로 이동하면 진행률이 초기화되는지 확인합니다.
6. 장시간 멈춤·백그라운드 복귀 시 이전 미소 유지가 이어지지 않는지 확인합니다.
7. 중지·재시작·페이지 이탈 때 카메라 표시등이 꺼지고 새 세션 측정이 초기화되는지 확인합니다.
8. Network에서 모델 다운로드 외에 영상·랜드마크 업로드가 없는지 확인합니다.
9. 조명/안경/각도/모바일별 반응과 최근 120개 표본 통계를 기록해 임계값을 조정합니다.
